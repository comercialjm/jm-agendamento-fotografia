# Agendamento Fotografia — JM Code Studio

Plataforma SaaS de agendamento para profissionais de fotografia.

## Estado

Projeto em preparação técnica.

A baseline documental foi aprovada para início do desenvolvimento, mas aplicação,
migrations, integrações e validações executáveis ainda estão em construção.

## Stack aprovada

- Java 21
- Spring Boot
- Spring Data JPA / Hibernate
- Spring Security
- PostgreSQL
- Flyway
- React
- TypeScript
- Vite
- Docker Compose

## Estrutura

```text
backend/          aplicação Java/Spring Boot
frontend/         aplicação React/TypeScript
infra/            infraestrutura local
docs/reference/   documentação de referência

docs/validation/  evidências de validação
scripts/          scripts auxiliares
